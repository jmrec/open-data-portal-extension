A typo fix, a clearer sentence in the docs, a question about how a dataset is coded, or a single barangay name that doesn’t match the PSGC is worth sending. Small fixes often save the next person hours, and good questions show us where the docs or the tools need work. If you think your contribution is too minor to bother with, send it anyway =D

## Ways to contribute

- **Small fixes**: Typos, broken links, unclear wording, or outdated dataset notes.
- **Questions**: Ask about a dataset, a PSGC code, or how something works. Unanswered questions point to gaps in the docs.
- **Data work**: Find Philippine public datasets that refer to places, and check how they are named and coded.
- **PSGC mapping**: Help match place names in datasets to Philippine Standard Geographic Code (PSGC) entries, including spelling variants, renamed or merged municipalities, and barangays that appear under more than one name.
- **Code**: Build the auto-tagging tools, catalog features, and place-first browsing.
- **Documentation**: Improve the README, guides, and examples so new contributors can get started.
- **Testing and review**: Check tagging results against source records and report mismatches.

*[PSGC]: Philippine Standard Geographic Code
